# Tradie Business Hub — V1

A responsive front-end MVP for simple business admin tools for Australian tradies.

## Included
- Public landing page
- Responsive dashboard
- Quote builder with GST preview
- Invoice builder with GST preview
- Hourly-rate calculator
- GST calculator
- Templates/checklists area
- Google review response generator
- Pricing section
- Login placeholder

## Next build
Connect real authentication, database/storage, PDF generation, email/SMS sending, payments/subscriptions and user accounts.

## Run
Open `index.html` in a browser, or deploy the folder with GitHub Pages/another static host.
